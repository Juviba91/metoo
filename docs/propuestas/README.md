# Propuestas

SQL y diseños **sin aplicar**, para discutir antes de construir.

Nada de aquí está en la base. Las migraciones de verdad viven en
`supabase/migrations/` y se aplican antes de mergear; esta carpeta existe
justamente para que una propuesta no acabe aplicada por inercia al estar
guardada al lado de ellas.

Cuando una propuesta se acepta, se mueve a `supabase/migrations/` con su fecha
y se aplica.
